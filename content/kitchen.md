faq:
  - q: 예림보드 럭스 MR의 MR은 무슨 뜻인가요?
    a: MR은 Moisture Resistance(내수)의 약자입니다. KS F 3200:2022 흡수두께팽창률 시험에서 기존 럭스 보드 9.2%, 럭스MR 보드 6.5%(MR 기준 7.0% 미만)로 약 30% 개선됐고, 주방처럼 물과 습기에 자주 닿는 가구에 씁니다. 다만 Prestige Glass(E0 R 보드)와 Prime UV(E1)는 MR 표기가 없습니다.
  - q: Prestige Glass는 진짜 유리인가요?
    a: 아닙니다. 유리 감성의 Prestige Glass PC 1.5T 를 E0 R 보드 15T 앞뒤에 붙이고, 옆면은 ABS Glass 에지 45° 면취로 마감한 도어재입니다. 유리보다 가볍고 충격에 강하다는 점을 내세우며, 내오염·내지문 표기가 있습니다. 럭스MR 가운데 MR(내수) 보드 표기가 없는 라인입니다.

예림 키친의 기본 자재는 예림보드 럭스ᴹᴿ입니다. 주방은 물·열·손자국이 매일 닿는 자리라, 어떤 표면재가 관리에 유리한지가 컬러보다 먼저입니다. 유리 감성의 Prestige Glass, 금속 질감의 Prestige PET, Supreme PP 세라믹 문, 매트·우드 컬러까지 표면재별 특징을 제품 페이지에 정리합니다.

## 라인 한눈에

| 라인 | 소재 | 보드 등급 | MR | 기능 |
|---|---|---|---|---|
| Prestige | Glass | E0 R | 없음 | 내오염·내지문 |
| | Acryl | SE0 | ● | 내오염·내지문·내스크래치·항균 |
| | PP | SE0 | ● | 내오염·내지문·일체화 |
| | PET | SE0 | ● | 내오염·내지문(일부 품목 제외) |
| Supreme | PP | E0 | ● | 내오염·내지문·일체화 |
| | PET Matt | E0 | ● | 내오염·내지문·일체화 |
| | PET Glossy | E0 | ● | 내오염 (내지문 글로시 제외) |
| Deco | PVC | E0 | ● | 내오염·항균(일부 품목 제외)·일체화 |
| Prime | MFB | E0 | ● | 내오염·내스크래치 |
| | UV | E1 | 없음 | 내오염·항균 |

도어·보드·필름을 같은 색으로 맞추는 일체화 컬러는 38종입니다(샘플북 p12). 특대 4x9(1,220×2,745mm) 재고는 매트 화이트 SM-01·매트 밀크화이트 SM-02, 방염 재고는 Prime MFB 소프트 화이트 MFB-200·윈체스터 월넛 MFB-303입니다(p07). 옆면은 Acryl·PP·Supreme PET Matt·MFB 대부분에 독일 레하우 에지를 씁니다(p10~11). 키친 도어재 문의는 ㈜예림키친 대표번호 1899-4115입니다(p86).

## 제품군 안내

예림 키친 자재는 2026-27 예림보드 럭스MR 도어재 샘플북의 도어재 4라인과, 예림 홈페이지의 바디재·부자재·플러스 아이템으로 나뉩니다. 한 페이지에 라인 하나씩, 색상 코드·보드 등급·에지를 표로 정리했습니다.

**도어재 (샘플북 기준)**

- [Prestige](/kitchen/prestige/) — [Glass](/kitchen/prestige/prestige-glass/)(E0 R, MR 아님) · [Acryl](/kitchen/prestige/prestige-acryl/) · [PP](/kitchen/prestige/prestige-pp/) · [PET](/kitchen/prestige/prestige-pet/) (Acryl·PP·PET 는 SE0 MR)
- [Supreme](/kitchen/supreme/) — [PP](/kitchen/supreme/supreme-pp/) · [PET Matt](/kitchen/supreme/supreme-pet-matt/) · [PET Glossy](/kitchen/supreme/supreme-pet-glossy/) (모두 E0 MR)
- [Deco](/kitchen/deco/) — [PVC](/kitchen/deco/deco-pvc/) (E0 MR, 하임 필름 코드 12색)
- [Prime](/kitchen/prime/) — [MFB](/kitchen/prime/prime-mfb/)(E0 MR) · [UV](/kitchen/prime/prime-uv/)(E1, MR 아님)

**바디재·부자재·가공 (홈페이지 기준)**

- [바디재](/kitchen/body-material/) — [MFC](/kitchen/body-material/body-mfc/) 14색(방염 F200·F303 포함) · [PVC](/kitchen/body-material/body-pvc/) 13색
- [부자재·조명](/kitchen/kitchen-accessories/) — [LED 조명시스템](/kitchen/kitchen-accessories/led-lighting-system/)과 헤펠레 부속품, 후드·수전·손잡이·식기건조대
- [에지·가공](/kitchen/edge-finishing/) — [레하우 에지](/kitchen/edge-finishing/rehau-edge/) · [폼플렉스](/kitchen/edge-finishing/formflex/) · [레이저 엣지 주문재 도어](/kitchen/edge-finishing/laser-edge-door/)

플러스 아이템 가운데 하임 인테리어 필름 매트 계열과 템바보드 TB-01~03 은 필름·월 제품 페이지에서 따로 다룹니다. 흡수두께팽창률은 KS F 3200:2022 시험 기준으로 기존 럭스 E0 보드 9.2%, 럭스MR 보드 6.5%이고 MR 보드 기준은 7.0% 미만입니다(샘플북 p.06). 이 기준이 적용되는 것은 MR 표기가 있는 라인이며, Prestige Glass(E0 R)와 Prime UV(E1)는 MR 이 아닙니다.

실물은 예림 본사 2층 전시장에서 볼 수 있습니다. 전시장에 모든 색상이 시공돼 있지는 않아, 특정 색상을 보려면 먼저 문의한 뒤 방문하는 편이 좋습니다. 싱크대와 같은 색상의 인테리어 필름도 구매할 수 있고(일부 컬러 제외), 예림키친 자재는 등록 대리점에만 납품됩니다.
